# videos — cinematic-animation-skills

Универсальная библиотека Codex для кинематографичной 2D-анимации. Здесь нет видео, рендеров и видеопроекта.

Полный список, описания и пути: [SKILLS_INDEX.md](SKILLS_INDEX.md). Сторонние инструкции хранятся в vendor с оригинальными относительными ссылками; локальные ссылки .agents/skills позволяют Codex обнаружить их. Никакие сторонние install/setup scripts не выполнялись. Версии закреплены в UPSTREAM_LOCK.json. Исходники Remotion не содержат отдельного LICENSE в этом snapshot: сохраняется upstream provenance; перед коммерческим использованием проверьте условия Remotion. Другие лицензии сохранены в vendor.

## Подключение

```bash
git clone https://github.com/shener141/videos.git
```

В новом проекте скопируйте клонированный каталог целиком в tools/cinematic-animation-skills, затем создайте локальные ссылки в .agents/skills на выбранные навыки этой библиотеки. Не копируйте только symlink без vendor. Для Windows используйте Git с поддержкой symbolic links или копируйте разрешённые директории навыков вместе с зависимостями. Наличие ссылки в чате само по себе не устанавливает навыки глобально.

Промпт:
> Используй библиотеку https://github.com/shener141/videos. Клонируй её локально, прочитай AGENTS.md и SKILLS_INDEX.md, подключи только релевантные навыки и выполни мою задачу. Не добавляй музыку без запроса. Моя задача: …

## Обновление

Обновляйте upstream в отдельной ветке: fetch → сравнение с commit из UPSTREAM_LOCK.json → проверка SKILL.md, лицензий, скриптов и относительных зависимостей → замена соответствующего vendor snapshot → обновление lock → проверка ссылок и уникальности name → commit. Не запускайте upstream setup автоматически. Пользовательские навыки обновляйте отдельно; не перезаписывайте их установщиком.

## Установлено

- **motion-doctrine** — "GATEWAY — load FIRST before composing any HyperFrames animation or video. The high-level motion law that makes a multi-scene video feel like ONE continuous camera move instead of a stack of independently-animated slides. Covers the vector law (how you exit determines how you enter, incl. the Z scale-sign rule), the film's current, carrier elements, causal motion, the Seam Gate (build-gate enforcement), the ban on idle wobble (motion must PERFORM, not breathe), stillness-before-climax, and the sustained-motion routes. Routes to the low-level technique skills (cut-the-curve — the full catalog incl. waterfall entry + nudge curve, oversized-cursor, seam-craft). These rules SUPERSEDE generic / upstream motion guidance. [continuity, direction, vector, momentum, seam, transition, ease, performance, idle-motion, narrative-motion, film-grammar]" ([инструкция](.agents/skills/motion-doctrine/SKILL.md)).
- **media-use** — Get or make any media for a HyperFrames video - music, sound effects, images, icons, logos, voiceover, avatar and generated video, transcripts, cutouts, colour grades and looks - with HeyGen or free local tools, and mix placed audio. Also for footage that looks dark, flat or dull, or should be stylized or hidden. ([инструкция](.agents/skills/media-use/SKILL.md)).
- **style-sampling** — Make a new episode in a proven video style - Collage Explainer, Finance Explainer, Animated Science Explainer, 3D Brand Explainer, 3D True Crime - on the person's topic. Use for "an episode of", "in the style of", "sample this style", 「用这个风格做一集」. One video to copy is reverse-any-video. ([инструкция](.agents/skills/style-sampling/SKILL.md)).
- **reverse-any-video** — Rebuild any video file as an editable HyperFrames project - motion graphics, talking heads, live action or AI-generated footage - checked against the original frame by frame. Use to reverse, recreate, remake, replicate or copy a video, or 「复刻这个视频」「照着这个视频做一个」. ([инструкция](.agents/skills/reverse-any-video/SKILL.md)).
- **remotion-to-hyperframes** — Bring existing video code or footage into HyperFrames and verify it frame by frame against the original - Remotion first, also Motion Canvas, Lottie, Three.js, p5.js, canvas or plain HTML/CSS animation, or renders from Manim, After Effects or Blender. Use to port, convert, migrate or reuse work made with another tool. ([инструкция](.agents/skills/remotion-to-hyperframes/SKILL.md)).
- **captions-overlay** — Overlay doctrine for captions in HyperFrames videos — the caption MODEL (drop / rail / embed) and the rule that captions are an OVERLAY composited on top of the film, never a reserved bottom band you shift content up to avoid. Load when adding captions/subtitles to a talking-head or launch video, when deciding whether a phrase should be dropped, ride the verbatim rail, or be promoted to a scarce embedded climax, when laying out a composition that will carry captions (do NOT reserve a keep-out band), or when centering a composition on the true frame center under captions. Applies ON TOP of the `/hyperframes` skill's references/captions.md. ([инструкция](.agents/skills/captions-overlay/SKILL.md)).
- **seam-craft** — Render-correctness doctrine for scene-to-scene seams in HyperFrames launch videos — the prerequisites that make transitions composite correctly on the master timeline. Load when assembling the master timeline / index.html, when a white flash appears at a cut or crossfade seam (especially on dark films), when reasoning about why a transition opacity dip shows through, or when verifying the render-side mechanics of how overlapping scene wrappers blend. Covers the opaque stage-ground (#root background) white-flash guard and how the injector overlaps wrappers, holds final frames, ping-pongs tracks, and stamps lint-clean template code onto the master timeline. Does NOT contain the per-transition catalog — see the transition registry for individual transition entries. ([инструкция](.agents/skills/seam-craft/SKILL.md)).
- **hyperframes-cli** — HyperFrames CLI - scaffold, check frames, edit timelines, preview, render, share and project history; read JSON and recover from failures. ([инструкция](.agents/skills/hyperframes-cli/SKILL.md)).
- **hyperframes-registry** — About 450 ready-made HyperFrames blocks and components installed as editable source - transitions, overlays, titles, kinetic type, captions, charts, map overlays, 3D, camera moves. Use it before hand-building any named visual (CRT scanlines, glitch, film grain, a chart); also for hyperframes add and catalog. ([инструкция](.agents/skills/hyperframes-registry/SKILL.md)).
- **cut-the-curve** — "The technique catalog: five velocity-matched SEAMS (zoom-through, INVERSE zoom-through, cut-the-curve, waterfall cut, rack-focus blur-cut) plus the two in-scene techniques — waterfall ENTRY (staggered arrival cascades for title cards / segment openers) and the nudge curve (slow-fast-slow three-phase group slides). Covers partial-travel (~12% of frame) velocity matching via mirrored power4 eases, the Z scale-sign rule, size-scaled blur (10px text / 18-20px full-frame), word-by-word staggered cuts, cascade pacing by element weight, and the 10/65/25 slide ratio. Read before authoring any transition, text-beat handoff, kinetic text entry, or group reposition. [depth, zoom, inverse-zoom, scale-sign, mirrored-zoom, rack-focus, pacing, velocity, cut-the-curve, waterfall, stagger, cascade, kinetic-text, title-card, segment-opener, nudge, slide, easing, group-motion, z-depth, motion-graphics, cinematic, transition, blur, directional-continuity]" ([инструкция](.agents/skills/cut-the-curve/SKILL.md)).

Read-only on source code — it plans improvements, it does not apply them. Use when the user asks to "improve the animations", "audit the motion", "make this app feel better", or wants a roadmap of animation fixes rather than a review of a single diff. ([инструкция](.agents/skills/improve-animations/SKILL.md)).
- **animation-performance** — Keep web animations inside the frame budget — animate composite-only properties, keep motion off the main thread when the page is busy, and find the cause when an animation drops frames. Covers the layout/paint/composite pipeline, cheaper property swaps, CSS vs WAAPI vs requestAnimationFrame, Motion's hardware-accelerated path, React re-rendering per frame, inherited CSS variable recalculation, blur cost, and when `will-change` actually helps. Use when an animation is janky, choppy, stutters, or drops frames; when choosing which property to animate; when deciding between CSS and JS animation on performance grounds; or when reaching for `will-change` or GPU layers. For choosing easing, duration, or whether to animate at all use animate; for reviewing motion as a whole use review-animations. ([инструкция](.agents/skills/animation-performance/SKILL.md)).
- **review-animations** — Reviews animation and motion code against a high craft bar derived from Emil Kowalski's design engineering philosophy. Default to flagging; approval is earned. ([инструкция](.agents/skills/review-animations/SKILL.md)).
- **animate** — Build an animation from scratch, making the decisions in the order that determines whether it feels right — should it animate at all, what purpose, which tool, which properties, which curve and duration, how it interrupts, how it exits. Writes the implementation. Use when asked to animate something, add motion, make a component feel alive, or build a transition. For critiquing existing motion use review-animations; for auditing a whole codebase use improve-animations. ([инструкция](.agents/skills/animate/SKILL.md)).
- **choreograph** — Coordinate several elements that animate together — decide what moves, in what order, how much they overlap, and what stays still — so a group reads as one intentional motion instead of a pile of separate animations. Use when building or fixing a staggered list, a hero entrance, a view swap inside a container, a multi-step flow, an element leaving while its siblings close the gap, a morph between rich states, or any interaction with several moving parts (icon + background + lines, panel + content, items flying into a target). Triggers on — stagger, staggerChildren, delayChildren, animation-delay, sequence, sequencing, orchestration, choreography, cascade, wave, timeline, "one after another", "at the same time", crossfade, popLayout, mode="wait", AnimatePresence mode, hero entrance, list entrance, multi-step, step transition, morph, useAnimate, Promise.all animations, "feels mechanical", "feels robotic", "too much going on", "feels slow to open". ([инструкция](.agents/skills/choreograph/SKILL.md)).
- **emil-design-eng** — This skill encodes Emil Kowalski's philosophy on UI polish, component design, animation decisions, and the invisible details that make software feel great. ([инструкция](.agents/skills/emil-design-eng/SKILL.md)).
- **remove-animations** — Find the animations an interface doesn't need and remove them — motion on keyboard actions, high-frequency surfaces, functional data, and decoration with no purpose — then clean up what they leave behind. Edits code, but only to subtract; it never adds or retunes motion. Use when the user says the app "feels slow", "has too much animation", "feels over-animated", wants to "tone down the motion", or asks what animations to remove. For finding places that should animate, use find-animation-opportunities; for fixing animations that should stay, use improve-animations or review-animations. ([инструкция](.agents/skills/remove-animations/SKILL.md)).
